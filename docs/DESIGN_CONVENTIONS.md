# اتفاقيات التصميم (UI Conventions)

_مرجع حيّ لمبادئ الواجهة في النظام. يتطبّق على أي شغل جديد. آخر تحديث 2026-09-18._

## 1. اللون = معنى، مش زينة
- **الألوان الدلالية (traffic-light): 🟢 أخضر / 🟠 برتقالي / 🔴 أحمر** محجوزة لـ**الحالات** (تفاعل، نتيجة، صحة الليد، نجاح/تحذير/خطأ). ماتستخدمش للتزيين.
- **لون البراند (#2F6BD3)** للعناصر التفاعلية/الأساسية (أزرار، اختيار نشط، روابط).
- **المحايد (رمادي/edge)** للبنية (حدود، خلفيات، نص ثانوي).
- **2-3 ألوان في الشاشة الواحدة** كحد أقصى، عشان اللون يفضل ليه قيمة.

## 2. تلوين الأيقونات (القاعدة العامة)
- **الأيقونة محايدة افتراضياً** (بتورث لون النص، درجة واحدة).
- **تتلوّن دلالياً فقط لو بتحمل حالة** لها valence (كويس/وحش/محايد). مثال: مكالمة مردود عليها = ☎ أخضر · مكالمة فائتة = 🟠؛ واتساب رد = صحّين أخضر · اتسلّم بس = صح واحد برتقالي.
- **أيقونة مجرد ليبل/فعل/تنقّل** (اتصال في سياق محايد، إعدادات، قائمة) **تفضل محايدة** — تلوينها ضوضاء.
- المحصلة: مافيش "سيستم قوس قزح"؛ اللون بيشتغل كإشارة مش ديكور.

## 3. أعِد استخدام مكوّنات النظام، ماتخترعش شكل
- أي كنترول جديد يستخدم الموجود بنفس النمط: `SearchableSelect` (فيه نقطة لون اختيارية للـoptions)، `Modal`، `Button`، `Select`، chips، segmented control، الـtraffic-light palette.
- ممنوع إيموجي كعنصر UI — استخدم SVG/CSS. (تفصيل في [[match-system-ui]].)

## 4. منتقي التاريخ/الوقت (Date-time) — كمبوننت واحد موحّد
- **تصميمنا، مش الـnative** (`<input type=datetime-local>` بيفتح تقويم مختلف كل جهاز).
- **popover عائم** (مايكبّرش الفورم)، RTL/عربي، بحدّ أدنى/أقصى قابلين للضبط (ماضي فقط / مستقبل فقط / نطاق).
- نفس الكمبوننت لكل حقل تاريخ+وقت في النظام (أنشطة، جدولة، تقارير) — بس نغيّر إعداد المسموح.

## 5. أنماط الإدخال السريع (Fast entry)
- **اختصارات للحالات الشائعة** (كليك واحد) + **"حالة تانية"** يكشف التفاصيل النادرة (progressive disclosure).
- **الإدخال المشتق يُعرض read-only** (المستنتج) مع إمكانية التعديل، مش خانة فاضية.
- الحقول الثانوية/النادرة تتطوى في سطر واحد (زي وقت النشاط التلقائي).

## 6. عام
- ثنائي AR/EN RTL: النصوص تتحط بالطريقتين؛ الاتجاه يتقلب مع اللغة.
- خط Cairo، canvas فاتح (#F7F8FA / #0A0D13)، حواف مدوّرة، ثيم فاتح/غامق.
- كل حقل/إشارة يبقى **مسمّاه واضح بيخص إيه** (مثال: "حالة الليد" مش "الحالة"، عشان مايتخلطش بحالة النشاط/التفاعل).
